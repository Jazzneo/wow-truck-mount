TRUCK MOUNT - PLAYER INSTALL (WoW 3.3.5a)

Windows:             double-click install-client.bat
                     (if WoW is not found: drag your WoW folder onto install-client.bat)
Linux / Steam Deck:  bash install-client.sh   (or: bash install-client.sh /path/to/WoW)
By hand:             copy patch-5.MPQ into WoW\Data\ and delete the WoW\Cache folder.

In game: Spellbook > Mounts > "Truck with Lights" / "Truck with No Lights".
The server must have the truck installed too (ask your admin).

Remove it: uninstall-client.bat or bash uninstall-client.sh
